## 🚀 Overview

This project is a **prototype landing website** for a home tuition coaching platform.  
It focuses on clean design, clear service communication, and a user-friendly browsing experience.

The primary objective is to demonstrate how a coaching institute can present its offerings through a modern web interface.

> ⚠️ This project is built for **demonstration and viewing purposes**.

---

- Modern and professional landing page layout
- Clean service presentation for coaching programs
- Tutor-focused content sections

## 🛠️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/harshpandey/shikshabhavan-home-tuition.git
   ```
2. Open the project folder:
   ```bash
   cd shikshabhavan-home-tuition
   ```
3. Run the site:
   - Open `index.html` directly in your browser, or
   - Use VS Code Live Server for a local development server.

---

## 🌐 Deployment (GitHub Pages)

To deploy on GitHub Pages:

1. Push your code to a GitHub repository.
2. Go to **Repository Settings → Pages**.
3. Under **Source**, choose:
   - Branch: `main`
   - Folder: `/ (root)`
4. Save and wait for deployment.
5. Your site will be available on the GitHub Pages URL.
